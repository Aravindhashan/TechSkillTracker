 How Tech Skill Tracker Should Work

### 1. Data Pipeline  
- Dataset (`job_listings_50k.csv`) is pre-stored in `/data` folder.  
- `data_loader.py` loads it via `pandas.read_csv()`.  
- Users **do not upload files**; app loads fixed dataset on startup.

### 2. Processing and Cleaning  
- `data_cleaner.py` auto-cleans the data: removes missing values, duplicates, invalid salaries.  
- Standardizes location names, skill formatting, converts dates.  
- Dataset cached with `@st.cache_data` for fast reloads.

### 3. Analytics & Visualization  
Multiple Streamlit tabs auto-load data and show:  
| Tab | Purpose | Example Components |  
|------|---------|--------------------|  
| Overview | Dataset metrics | Total jobs, top skills/companies, city stats, sector pie chart |  
| Visualization | Interactive charts | Bar, heatmap, trend charts with Plotly |  
| Forecast | Skill demand projection | Prophet/Linear Regression forecasts for 12 months |  
| Salary Insights | Salary distribution | Histograms/box plots by skill, city, experience |  
| Recommendations | AI skill suggestions | Based on co-occurrence or DistilBERT |  
| Report | PDF export | ReportLab-generated summary with charts |

### 4. Machine Learning  
- Forecasting with Prophet on skill time-series.  
- Salary Predictor using Random Forest regression.  
- Skill Recommender using co-occurrence matrix or NLP similarity.  
- Models stored in `/models`, loaded automatically without retraining.

### 5. PDF Reporting  
- Generates exportable PDF reports with analytics and charts.  
- Reports saved in `/reports` and downloadable from UI.

### 6. System Control  
- Dataset changes only by you in `/data`.  
- App detects updated CSV on next launch automatically.  
- Prevents inconsistent/unverified user uploads.

## Development Prompt

You are finalizing “Tech Skill Tracker – BI Dashboard for Indian Tech Market” with a fixed dataset.

**Goals:**  
- Load pre-stored dataset (`data/job_listings_50k.csv`) on Streamlit start.  
- Auto clean, validate data on load.  
- Show interactive tabs: Overview, Visualization, Forecast, Salary Insights, Recommendations, PDF Report.  
- Use Plotly (charts), Prophet (forecast), scikit-learn (salary), ReportLab (PDF).  
- Modular error-handled functions.

**File Structure:**  
```
app.py  
/data/job_listings_50k.csv  
/modules/  
  data_loader.py  
  data_cleaner.py  
  ml_forecast.py  
  recommendation_engine.py  
  salary_predictor.py  
  pdf_generator.py  
/models/ (trained models)
```

**Functionality:**  
- Load & cache fixed dataset (`data_loader.py`).  
- Clean & format (`data_cleaner.py`).  
- Streamlit UI with tabs (`app.py`).  
- Forecast demand (`ml_forecast.py`).  
- Recommend skills (`recommendation_engine.py`).  
- Predict salary (`salary_predictor.py`).  
- Generate PDF (`pdf_generator.py`).

**Streamlit Rules:**  
- No upload widgets, fixed dataset only.  
- Cache for efficiency (`@st.cache_data`, `@st.cache_resource`).  
- Use `st.tabs` or `sidebar.radio` for navigation.  
- Configure page with `st.set_page_config(page_title="Tech Skill Tracker", layout="wide")`.  
- Show developer info footer.

**Expected Output:**  
- Fully functional BI+ML dashboard, auto-loading visualizations and models.  
- Downloadable PDF report button.  
- No user file uploads or model retraining.

**Extras:**  
- Use `st.error()`, `st.warning()` for messages.  
- Consistent styling across tabs.  
- Optional logging folder (`/logs`).

## Setup Guide (Markdown)

```
# Tech Skill Tracker - Setup Guide

## Requirements
- Python 3.8+
- Packages: streamlit, pandas, numpy, plotly, prophet, scikit-learn, reportlab

## Installation
1. Clone repo  
2. Navigate to project folder  
3. Create virtual env: `python -m venv venv`  
4. Activate env and install packages: `pip install -r requirements.txt`

## Running the App
- Place `job_listings_50k.csv` in `/data` folder  
- Run: `streamlit run app.py`  
- Open displayed URL in browser

## Notes
- Dataset update: replace file in `/data` and restart app  
- Reports saved in `/reports` folder  
- Logs (if enabled) saved in `/logs`

Machine Learning Models Used
1. Forecasting Model (Time-Series Forecasting)
What ML: Facebook Prophet or Linear Regression

Purpose: Predict future demand for each tech skill over the next 6–12 months based on historical job posting trends.

How it works:

Input data is the cleaned dataset aggregated as time series — counts of job listings for each skill by date.

Prophet models trend, seasonality, and holiday effects in job posting frequencies to forecast future demand.

Linear regression provides a simple baseline for trend prediction.

Output: A forecast graph showing predicted skill demand over time, helping users anticipate which skills will be valuable.

2. Salary Prediction Model
What ML: Random Forest Regressor or other regression algorithms (e.g., Linear Regression) from scikit-learn

Purpose: Estimate expected salary for a specific skill, location, and experience level.

How it works:

Trained on historical salary data extracted from the job listings, using features like skill, city, and years of experience.

The model learns relationships and patterns in the dataset to predict the likely salary range.

Output: Predicted salary figure in LPA (lakhs per annum) personalized to user input parameters.

3. Skill Recommendation Engine
What ML: Co-occurrence matrix analysis or NLP-based similarity (optionally with pre-trained DistilBERT embeddings)

Purpose: Suggest new or related skills based on the user’s dream job or current skills.

How it works:

Co-occurrence: Analyzes frequently appearing skill pairs or groups in job postings to recommend complementary skills.

NLP similarity: Uses vector embeddings of job roles and skills to find semantically close skills for recommendation.

Output: List of suggested skills tailored to the user’s career goals or existing skill set.

Summary of ML Workflow Integration
Clean the dataset for reliable input.

Aggregate data for time-series forecasting (skill demand).

Train or load pre-trained regression models for salary prediction.

Analyze skill patterns or embeddings for recommendations.

Load these models in Streamlit once at startup (cached for performance).

Present dynamic predictions, forecasts, and recommendations in the dashboard UI.
